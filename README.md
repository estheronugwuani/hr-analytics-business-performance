# HR Analytics & Business Performance Analysis

## Project Overview

This project involved analyzing an employee dataset to identify data quality issues, explore workforce patterns, develop key performance indicators (KPIs), and generate business insights to support HR decision-making.

The dataset contained 1,480 employee records across 38 fields.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Pivot Tables
- KPI Analysis
- Data Visualization

## Data Cleaning

The dataset was reviewed and cleaned before analysis.

Key data cleaning activities included:

- Removed 7 duplicate records, resulting in 1,473 unique employee records.
- Identified 57 missing values in `YearsWithCurrManager` and filled them using the median value of 3.
- Corrected 7 inconsistent `BusinessTravel` entries from `TravelRarely` to `Travel_Rarely`.
- Reviewed categorical fields for inconsistencies.
- Checked 8 numeric fields for potential outliers; no outliers requiring correction were identified.
- Identified `Over18` as a redundant field because all records contained the same value.

## Exploratory Data Analysis

The analysis examined employee attrition, overtime, satisfaction, and performance patterns.

Key areas analyzed included:

- Department-level attrition
- Overtime rates across job roles
- Job, environment, and relationship satisfaction
- Performance ratings
- Workforce distribution and KPIs

## Key Findings

- Overall employee attrition rate was 16.09%.
- Sales recorded the highest departmental attrition rate at 20.58%.
- Research & Development recorded the lowest departmental attrition rate at 13.81%.
- Research Scientists had the highest overtime rate at 33.22%.
- Lower satisfaction levels were associated with higher attrition rates, with Environment Satisfaction showing a notable difference between low and high satisfaction levels.
- Performance ratings were concentrated at ratings 3 and 4, with no records for ratings 1 and 2.

## Business Insights

The analysis highlighted employee attrition as an important workforce metric, particularly within the Sales department. The relationship between satisfaction levels and attrition also provided useful insight into potential workforce retention considerations.

The findings demonstrate how data cleaning, exploratory analysis, and KPI reporting can be combined to transform employee data into actionable business insights.

## Project Outcome

This project strengthened practical skills in data cleaning, exploratory data analysis, KPI development, workforce analytics, and business reporting using Microsoft Excel.
